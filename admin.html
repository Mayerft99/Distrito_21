📋 Cómo configurar Supabase (primera vez)

  1. Ve a supabase.com y crea una cuenta gratuita, luego un nuevo proyecto.
  2. Abre SQL Editor y pega el contenido completo de supabase-setup.sql incluido en este proyecto. Ejecuta.
  3. Ve a Storage → crea un bucket llamado productos → márcalo público.
  4. Ve a Authentication → Providers → Email y desactiva "Allow new users to sign up" — este panel no tiene registro público, solo login.
  5. Ve a Authentication → Users → Add user y crea tu usuario admin (email + contraseña).
  6. Ve a Project Settings → API, copia la URL y la anon key, pégalas arriba y presiona Guardar.
  7. Vuelve a la pantalla de acceso e inicia sesión con el usuario que creaste en el paso 5.

🔒 Cómo queda protegido

La lectura del catálogo (lo que ve un visitante) sigue siendo pública. Pero crear, editar o eliminar categorías, productos, o subir imágenes ahora exige una sesión real de Supabase Auth — las políticas de la base de datos verifican auth.uid(), no una contraseña guardada en el navegador. Alguien con tu anon key puede leer el catálogo, pero no puede escribir nada sin iniciar sesión con una cuenta que tú hayas creado.
